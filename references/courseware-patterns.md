# 按教学任务选交互与画风

以下六项是外部课件参考。每项先写原课中可以看到的设计，再给出新课的做法与可检验的结果。用自己的内容、场景和界面实现；来源链接供备课者查阅。

| 参考课件 | 原课里值得看的设计 | 迁移到新题时怎样做、怎样验 |
|---|---|---|
| [Designed to Scale](https://designed-to-scale.vercel.app) | 用能逐步推进的动画图讲系统设计。每一步能单独看清组件之间的关系。 | 讲班级借书系统的缓存时，用平面架构图固定读者、缓存和书库的位置。先借同一本书两次，再清缓存重试。学生能指出哪次访问了书库，并用累计查询次数核对。 |
| [Learn Arduino](https://learn-arduino-red.vercel.app) | 同一堂课可看 3D 开发板、引脚、示例程序和串口监视器。旋钮和按键给程序提供可操作的输入。 | 讲旋钮控制指示灯时，用近实物 3D 让学生找到旋钮和引脚。转动旋钮，看采样值跨过程序阈值、灯随之点亮；改阈值再试。同一位置可以得到相同读数、不同灯态。 |
| [Learn ESP32](https://learn-esp32.vercel.app) | Wi-Fi 控灯把手机请求和板上 LED 放进同一件事；智能车位还把距离、信号灯和手机状态联系起来。 | 讲远程开窗时，让学生从手机面板发指令，在装置视图看电机，再看位置传感器回报。分别显示“指令已发”和“窗已打开”；模拟断连后检查这两个状态能否区分。 |
| [Backcountry 101](https://backcountry-101.vercel.app) | 操作按步骤展开，场景中保留工具及上一步的结果，旁边可切换步骤、讲解和提示。野外手册式的轮廓线便于从一堆器材里认出当前要用的物件。 | 迁移到标本夹制作时，用手册插画或插画式 3D 表现对象。学生放入标本、合上夹板、再束紧；回到第二步应看到已放好的标本和仍可操作的夹板。 |
| [Electronics 101](https://electronics-101-six.vercel.app) | 把电路图、面包板和 3D 工作台连到同一个电路问题。看万用表一课时，量什么、插哪个孔、探针碰哪里都是操作的一部分。 | 讲滑动变阻器时优先用近实物 3D：滑片能抓、四个接线柱能分清。用原理图标出接入的电阻丝。固定滑片，从左端换到右端，再向同一方向推；阻值与电流的变化方向应一起反转。 |
| [Protocol Explorer](https://protocol-explorer-alpha.vercel.app) | 网络图上逐包播放通信过程，选中一个包还能展开检查内容，把“走到了哪儿”和“这条消息是什么”联系起来。 | 讲 DNS 查询时，用二维拓扑和事件列表共用选中状态。学生点回复包，两处同时定位到同一跳，详情显示与查询对应的域名和返回值；倒退一步后可重新追踪。 |

## 怎样判断画风选对了

- 让学生辨认接点、抓握位置或观察遮挡时，先用可旋转的 3D 实物和可辨识的材质。上色强调当前接入的部分，镜头转动时保留状态。
- 让学生从相似工具中选一件、按顺序处理材料时，可以用手册插画。若当前步骤依赖正反面或装配方向，用可旋转的插画式 3D，保留方向线索。
- 让学生解释请求去哪、哪条消息先到、数值何时变化时，把空间留给拓扑、时间轴或曲线。固定节点位置、时间方向和读数尺度，让相邻状态可以直接对照。
- 先做一个可操作片段。以课堂投影和手机尺寸看操作前后，检查学生能否找到下手的位置、辨认结果、据此回答预测题。看不清接点就调镜头或加局部图；看不清顺序就允许停在关键一步。用这个结果决定是否保留画风。
