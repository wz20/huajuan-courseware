# 运行时接口

每堂课是一个目录，含 lesson.json 与 scene.js。构建器只接受可信本地 JS，使用 Python 标准库生成离线单页。外部图片、字体和模型若新增，由课程作者内嵌数据或明确改为附带资源的目录交付。Three.js 0.185.0 与 MIT 许可随包。

| 课程字段 | 用法 |
|---|---|
| title / question | 学生能复述的问题和操作引导 |
| control / unit / min / max / initial | 主控件名称、单位、有限范围和可复现实验的起点 |
| step | 数值步长，默认 1 |
| challenge / limit | 可实际操作的挑战；模型忽略的因素 |
| three | 为 true 时将离线 WebGL 渲染库内联进 HTML |

scene.js 定义两个函数。

- `compute(value)` 返回含 `summary` 的模型。输入相同，模型输出相同。将适用单位、边界条件和解题依据写在课程源码或随附说明中。
- `createScene(stage)` 创建 Canvas、SVG、DOM 或 Three.js 场景并返回 `{draw(model), reset()}`。窗口缩放也会调用 draw，所以绘制不能偷偷推进实验。reset 在恢复默认值后、下一次 draw 前执行。
- 多个实验控件放进场景旁的语义化表单，用一份参数对象和纯领域函数求解；控件变化统一重新计算。只改变视角的操作不得修改实验参数。为新增视图提供键盘等效操作及读数。
- 单课壳自带响应式尺寸、键盘滑杆、结果文字和重置按钮。课程目录、课时进度、模型资源加载、多参数布局均可按项目扩展。
- 用带单位的原始值计算，再在显示层舍入；流程课保留事件轨迹，切换任务时清空旧轨迹。3D 场景只在创建时装配几何，复用材质，切换课节时清理画布、监听器、几何与纹理。
