# 课堂验收与跨题迁移标准

1. **纯模型独立断言测试（先于视觉验证）**：
   - 从教材、硬件手册或数学推导独立选取至少 3 组有判别力的标准输入与预期输出（初值、反向/极端边界、多步状态演化或错误输入边界），写入 `lessons/<slug>/model.test.cjs`。
   - 运行全部仓库测试：
     ```sh
     node --test tests/*.test.cjs lessons/*/model.test.cjs
     ```
2. **单文件离线打包与零错误验证**：
   - 运行 `python3 scripts/build.py lessons/<slug> build/<slug>.html`（需覆盖重建时加 `--overwrite`）。
   - 在真实浏览器（推荐无头 Chromium 或桌面浏览器直接双击 `file://` 打开）确认：
     - Console 报错数为 `0`，Page Error 为 `0`，无任何外部网络请求依赖（完全离线可用）；
     - 若含 Three.js 3D 模型，模拟 WebGL 失败场景仍能自动降级至 2D 原理图或架构视图完成核心学习动作。
3. **四维双向同步验证**：
   - **操作不串态**：旋转、缩放、俯视镜头后，主参数、执行周期、寄存器/电路读数保持不变；
   - **多端同源**：点选 3D 元件或点击 2D 原理图/步骤按钮时，检查器标签、顶部 KPI、指示脉冲与底层记录同步对齐；
   - **深浅与可逆**：切换深浅配色、点击代码里 `{{param}}` 参数芯片、执行单步推进、后退/重置，全部状态均可清晰解释；
   - **双视口可用性**：在 **桌面端 `1440×900`** 和 **手机端 `390×844`** 分别检查一次：无横向溢出、文字不压住教学对象、手机左侧目录可从左上按钮打开与收起。
4. **跨题迁移自查记录**：
   - 交付新课时必须附上：离线 `.html` 路径、源码目录路径、核心计算简化的教学边界（`limit`）、课堂演示路线与实测结果摘要。
