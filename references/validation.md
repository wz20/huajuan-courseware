# 课堂验收与跨题迁移

1. 从教材、权威资料或推导独立选取三个有判别力的标准答案。至少包括初值、极值或分支边界，避免只对照渲染代码自己的结果。给新课程添加独立的模型测试。
2. 浏览器离线打开最终交付文件。检查控制台和资源错误，改主参数，做相反操作，检查模型、读数、图像同时更新。进行一次重置。多步骤课额外检查末步、换题、回退（如提供）。
3. 在桌面与约 390 像素宽的手机视口各观察一次。看操作前、中、后三个状态；核对文字不压住教学对象，小屏能触控，关键控件能用键盘操作。空间题从另一角度观察遮挡，确认只改变相机不会触发模型变化。
4. 检查学生能否仅靠页面完成预测题。对比两个状态仍看不出规律时，加入同尺度对照或测量工具。描述具体失败操作，修复后复测。
5. 迁移评估用未进入案例库的题目，仅提供年级和目标。分别记录 Agent 有没有自行选对学生操作、模型有无依据、关键交互通过与否。一次样课的通过不代表对整个学科有效。视觉、模型、课堂试用的结果分开报告。
